LumaCycle — functional browser prototype

HOW TO RUN
1. Unzip the folder.
2. Open index.html in a modern browser, or host the folder on any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages).
3. On iPhone Safari, once hosted over HTTPS, use Share > Add to Home Screen for an app-like experience.

WORKING FEATURES
- Swipe left/right on the date strip to move one day at a time.
- Tap any visible date to select it.
- Log/remove period days.
- Log symptoms and intimacy by date.
- Full calendar view with logged period, predicted period, fertile window and ovulation estimate.
- Automatic cycle length detection from intervals between logged period starts.
- Automatic average period length calculation.
- Next-period and ovulation prediction.
- LocalStorage persistence so edits survive reloads.
- Settings, prediction summary and reset.
- Responsive mobile UI with original doodle artwork built in CSS.

IMPORTANT
This is a wellness tracking prototype, not a medical device. Prediction dates are estimates and should not be used as contraception or for diagnosis.
